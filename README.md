# goffamartin.github.io

Personal presentation website, published with GitHub Pages at <https://dev.goffa.cz> (Czech) and <https://dev.goffa.cz/en/> (English).

## Structure

```
index.html            Czech page – generated by `npm run build`, do not edit by hand
en/index.html         English page – generated by `npm run build`, do not edit by hand
CNAME                 custom domain for GitHub Pages
robots.txt            crawler rules + sitemap link
sitemap.xml           sitemap for search engines (both languages, linked via hreflang)
<key>.txt             IndexNow key (Bing, Seznam) – used by `npm run indexnow`
favicon.ico           default favicon (browsers request it from the root)
assets/
  css/styles.css      generated by Tailwind – do not edit by hand
  fonts/              self-hosted Inter (generated by copy:vendor)
  fontawesome/        self-hosted Font Awesome (generated by copy:vendor)
  icons/              favicons, touch icons, web manifest
  images/             photo, company logos, og-image.png / og-image-en.png (social previews)
src/
  index.template.html page structure with {{placeholders}} for texts – edit this instead of index.html
  i18n/cs.json        Czech texts
  i18n/en.json        English texts
  input.css           Tailwind source + custom CSS
  og-image.html       template for the social previews: /src/og-image.html (Czech), /src/og-image.html?lang=en (English)
scripts/
  build-html.js       renders index.html and en/index.html from the template and texts
  cache-bust.js       adds content hashes (?v=...) to CSS and og-image URLs in the generated pages
  copy-vendor.js      copies fonts and icons from node_modules into assets/
  indexnow.js         notifies Bing/Seznam about the sitemap URLs
tailwind.config.js    Tailwind theme (colors, font)
```

GitHub Pages publishes the repository root, so the files above that the site serves have to stay at the root.

## Editing the page

- **Text change:** edit the value in both `src/i18n/cs.json` and `src/i18n/en.json`.
- **New text:** add a `{{key}}` placeholder to `src/index.template.html` and the key to both JSON files (the build fails if a key is missing).
- **Layout or design change:** edit `src/index.template.html` (and `src/input.css`).

Then run `npm run build` and commit the generated files.

## Development

```sh
npm install
npm run build         # generate both pages + minified CSS + cache-busting hashes – run before committing
npm run watch:css     # rebuild only the CSS while editing styles
npm run copy:vendor   # only after updating Inter or Font Awesome
npm run indexnow      # after a deploy is live: ask Bing/Seznam to recrawl the sitemap URLs
```

`npm run build:css` still works and runs the full build. The generated pages and CSS are committed, because GitHub Pages does not run the build.
