# goffamartin.github.io

Personal presentation website, published with GitHub Pages at <https://dev.goffa.cz>.

## Structure

```
index.html            the page itself
CNAME                 custom domain for GitHub Pages
robots.txt            crawler rules + sitemap link
sitemap.xml           sitemap for search engines
favicon.ico           default favicon (browsers request it from the root)
assets/
  css/styles.css      generated by Tailwind – do not edit by hand
  fonts/              self-hosted Inter (generated by copy:vendor)
  fontawesome/        self-hosted Font Awesome (generated by copy:vendor)
  icons/              favicons, touch icons, web manifest
  images/             og-image.png (social preview)
src/
  input.css           Tailwind source + custom CSS
  og-image.html       template for assets/images/og-image.png
scripts/
  copy-vendor.js      copies fonts and icons from node_modules into assets/
tailwind.config.js    Tailwind theme (colors, font)
```

GitHub Pages publishes the repository root, so the files above that the site serves have to stay at the root.

## Development

```sh
npm install
npm run watch:css     # rebuild CSS while editing
npm run build:css     # minified build + cache-busting hash in index.html – run before committing
npm run copy:vendor   # only after updating Inter or Font Awesome
```

The built CSS is committed, because GitHub Pages does not run the build.
